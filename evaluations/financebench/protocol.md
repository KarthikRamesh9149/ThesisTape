# Independent financial statement questions

Can a multi-agent analyst answer sourced financial questions more accurately than a single Astra analyst with the same documents, calculator and spending limit? This study uses the FinanceBench authors' published questions, complete original PDFs and human reference answers. The 24 issuer-level pairs are separate from the development trials on Nintendo and Canon. Results measure open-book financial question answering. The official FinanceGym leaderboard also evaluates forward-looking research. [FinanceBench paper and public sample](https://github.com/patronus-ai/financebench/tree/cc39aeb4afdf33909ee1412188bf89035950c2eb)

**Sample.** Select eight issuers per published question type in the order metrics-generated, domain-relevant and novel-generated. Within each type sort the public IDs by SHA-256 of the fixed seed followed by the ID. Select the first eight whose issuer has not already been drawn and whose named PDF exists. Each issuer appears once. No answers, rationales or gold evidence affect sampling. Public benchmark exposure during model training is possible.

**Input.** Both arms receive the verbatim question and a gateway to the same complete PDF. The gateway can only read the source named in the packet. It requires the same cutoff on every search and verifies each cited page by reopening the document. The frozen repository revision proves that these PDF copies were public by 3 December 2024 at 17:29:01 UTC. This is an availability bound for the supplied copy. Research is frozen at midnight UTC on 4 December. The issuer's actual reporting period comes from the report. Human answers and annotated pages remain outside the research inputs.

**Assignments.** Run both arms once for each distinct company, sorting events and within-event order by the registered seed. Company pairs can proceed concurrently. Both arms plan, can request two more searches, use verified arithmetic, and can revise their answer. The team adds a separate outlook analyst and an independent reviewer. The single uses Astra throughout. Each assignment can use up to USD 0.45. All 48 outcomes count. Retain partial assignments, their charges and unresolved reservations. Lock all reports in Git before a masked evaluator receives a report with its question and human reference.

**Primary outcome.** Score one for a correct, explicit answer supported by the pages it cites, and zero otherwise. Financial quantities must match the requested metric, period, direction, currency and scale. Accept equivalent units and the reference answer's displayed rounding. For qualitative questions, require the substantive requested items without a contradictory material claim. Report answer correctness and citation support separately. FinanceBench evidence pages are zero-indexed and our PDF citations are one-indexed. Equivalent passages elsewhere in the same PDF can support a correct answer. An unreleased memo receives zero. The evaluator gets one anonymized memo, its cited passages, question, published reference and gold evidence, without its arm, cost or other answer. Require a verbatim answer witness for positive decisions and verify it against the locked memo.

**Analysis.** Publish scores for each arm, category and case, all disagreements, mean spending and unresolved bounds. Show the paired difference with an issuer-level 90% bootstrap interval using 20,000 seeded draws and the two-sided exact McNemar test. A positive lower interval bound supports an incremental factual accuracy claim within this sample. This test makes no claim about prediction accuracy or official leaderboard rank.
