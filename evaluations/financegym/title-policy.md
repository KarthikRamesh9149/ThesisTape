# Historical title lookups for empty investigations

During the official run both original investigators returned zero sources on an issuer question. The title they requested was case-sensitive. A historical revision existed under the same words with different capitalization. We added this procedure after observing that retrieval failure. The registered investigations keep their original outcome and costs.

Apply the procedure only if both original investigations completed searches and admitted zero passages, with no previously approved draft. Take up to three of their original searches, in stable record order. Only change the capitalization of entity titles that occur verbatim, ignoring case, in the user's question. Preserve their queries, filing search terms, result limits and exact cutoff. The same dated source gateway and original-byte checks apply. Raw discovery responses stay in the private operator record. No model selects new search terms.

When the lookup recovers evidence, the existing source editor and fresh independent reviewer can use those passages. The report is always qualified. It must identify aspects of the question that the dated sources do not establish. The editor uses the same USD 0.55 ceiling as other previously unanswered cases, subject to the overall project budget. It gets one allowance across the lookup and editing. The lookup uses zero model calls. An empty lookup produces no report. Preserve each original failure, new retrieval receipts, released text, elapsed time and cost. Count these reports separately from every earlier publication route.
