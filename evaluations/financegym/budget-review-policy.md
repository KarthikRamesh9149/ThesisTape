# Review an existing draft before funding a new investigation

The owner fixed the total project budget at USD 140 during the official run. At 252 completed primary investigations, 32 had stopped because the optional revision of a written draft exceeded the primary allowance. Offline replay found that 19 of those 32 already had a source-checked answer and a supporting section. All 32 original failures remain in the study. The 31 completed initial reviews in the independent research arm had a median estimated cost of USD 0.022784 and a maximum reservation of USD 0.0510375.

Before funding a new investigation, allow one fresh Sol review under a USD 0.075 ceiling. The eligible primary must have failed specifically at the unfunded optional revision. Replay every original paid request and dated search. Retain only paragraphs that pass the existing source, numeric and question-attribution checks. The draft must contain an answer and at least one different section. Freeze the list of independent investigations already dispatched when this rule was adopted. Those cases keep their existing routes.

The reviewer sees the unchanged question, cutoff, retained paragraphs, cited original passages and calculations. It receives no rubric or later outcome. Publish the original wording of independently accepted paragraphs only if an answer and another section survive. Mark the report qualified. If evidence or review is insufficient, use the registered independent investigation under the same total spending controls. Reconcile failed paid reviews too. Report both the original configuration and this prospective budget change. An accepted primary report can never be replaced.
